# Интерактивный тренажёр по математике для 5-го класса

Современный веб-тренажёр, созданный специально для работы на **электронных и интерактивных досках** в школьном классе, а также на компьютерах, планшетах и смартфонах.

---

## 🎯 Назначение и методическая основа

- **Целевая аудитория:** Ученики 5-го класса (10–12 лет) и учителя математики.
- **Сценарий урока:** Учитель или ученик выводит задание на электронную доску перед классом. Ученик решает задачу прямо на доске в поле для записей (пальцем, стилусом или мышью) и выбирает один из 4 вариантов ответа.
- **Соответствие программе ФГОС:** База из 28 тщательно выверенных заданий по 4 ключевым темам:
  1. **Арифметика:** порядок действий, распределительное свойство, деление с остатком, степени чисел, деление многозначных чисел (с нулями в частном).
  2. **Дроби:** правильные и неправильные дроби, выделение целой части, сложение и вычитание обыкновенных дробей с одинаковыми знаменателями, действия с десятичными дробями и их сравнение.
  3. **Геометрия:** периметр и площадь прямоугольника/квадрата, объём прямоугольного параллелепипеда, единицы измерения площади.
  4. **Задачи:** текстовые задачи на встречное движение, стоимость покупок, части и дроби от числа, уравнения в несколько действий.

## ✨ Ключевые возможности

1. **Большое поле для решения (Интерактивная доска / Черновик):**
   - Плавное рисование со сглаживанием линий (кривые Безье) со скоростью 60 FPS.
   - Фон с тетрадной клеткой (24 px) как в школьной тетради.
   - Поддержка касаний пальцем, стилуса и мыши с блокировкой нежелательной прокрутки экрана (`touch-action: none`).
   - Крупные инструменты: «Перо», «Ластик», выбор толщины линии, 4 цвета школьных чернил (синий, графитовый, зелёный, оранжевый).
   - Кнопки «Отменить» (история до 25 шагов) и «Очистить поле».
   - Автоматическая очистка поля при переходе к следующему заданию.

2. **Продуманная педагогическая обратная связь:**
   - Ровно 4 варианта ответа (сетка 2 × 2) с крупными буквами А, Б, В, Г.
   - Защита от случайных повторных нажатий: после выбора кнопки фиксируются.
   - **При верном ответе:** радостная похвала «Правильно!», звуковой мажорный перелив, кнопка «Дальше →» и мягкий автопереход через 2.5 секунды.
   - **При ошибке:** тактичное «Пока неверно», подсветка верного ответа, развёрнутое понятное математическое пояснение и большая кнопка «Следующее задание →». **Автопереход при ошибке отключён**, давая ученику время разобраться.

3. **Автономность и лёгкость (Zero Dependencies):**
   - Работает **100% локально** в любом браузере без обращения к внешним CDN и интернету.
   - Звуковые сигналы синтезируются на лету через **Web Audio API** (не требуют скачивания mp3/wav).
   - Никаких внешних шрифтов или тяжелых библиотек — мгновенная загрузка даже на слабых компьютерах.
   - Полная конфиденциальность: без регистрации, ввода имён и сбора персональных данных.

4. **Адаптивный интерфейс для больших экранов и проекторов:**
   - На электронных досках и ПК (1920×1080 и выше) всё занятие, холст и варианты умещаются **без вертикальной прокрутки**.
   - На смартфонах и планшетах блоки аккуратно перестраиваются: условие → черновик → удобные кнопки под пальцами.
   - Поддержка режима «На весь экран» (кнопка ⛶ в шапке) для скрытия рамок браузера на уроке.
   - Поддержка системного режима `prefers-reduced-motion` для доступности.

## ⌨️ Управление с клавиатуры

| Клавиши | Действие |
| :--- | :--- |
| `1`, `2`, `3`, `4` (или `A`, `B`, `C`, `D`) | Выбор соответствующего варианта ответа |
| `Enter` или `Пробел` | Переход дальше («Дальше» / «Следующее задание») |
| `Z` или `Ctrl + Z` | Отменить последнее действие на доске |
| `C` | Очистить поле для вычислений |
| `P` | Переключиться на инструмент «Перо» |
| `E` | Переключиться на инструмент «Ластик» |
| `F11` (или кнопка «Экран») | Развернуть на полный экран интерактивной доски |

## 🚀 Как запустить проект

### Вариант 1: Через Node.js (рекомендуется)
В папке проекта выполните:
```bash
npm start
```
Сервер запустится по адресу: **http://localhost:3000**

### Вариант 2: Прямое открытие без сервера
Благодаря отсутствию сборочных зависимостей, файл `index.html` можно открыть напрямую двойным кликом в любом современном браузере (Яндекс Браузер, Google Chrome, Microsoft Edge, Safari, Firefox).
